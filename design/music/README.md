# Music icon

`icon.svg` is the source for the launcher icon of the Music fork: five white equaliser bars on violet `#5B3FD9`.
It is deliberately not Music Assistant's logo, so the fork is not mistaken for an official build.

Generated Android resources (hand-kept in sync, the shapes are five paths):

- `androidApp/src/main/res/drawable/ic_launcher_foreground.xml` and `values/ic_launcher_background.xml`
- `wearApp/src/main/res/drawable/ic_launcher_foreground.xml` and `values/colors.xml`
